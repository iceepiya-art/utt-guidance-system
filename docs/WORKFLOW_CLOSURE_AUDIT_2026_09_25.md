# ตรวจการจบงานแนะแนว 25 กันยายน 2569

ตรวจข้อมูลสด 157 โรงเรียนและรายการหนังสือ นัดหมาย ผลแนะแนว ใน `backup/workflow-audit-2026-09-25.json` ผลสรุปอยู่ใน `backup/workflow-audit-result-2026-09-25.json`

- ผลแนะแนวที่มีรูป 50 รายการ; โรงเรียนที่มีประวัติแนะแนว 48 แห่ง (หน่วยนับต่างกัน)
- ไม่พบผลที่มีรูปและเชื่อมกับนัดหมายแล้วยังหลงในรายการนัดหมายค้าง
- นัดหมายค้างจริง 3 แห่ง: บ้านน้ำหมัน 10 พ.ย., บ้านแก่งวิทยา 12 พ.ย., ทองแสนขันวิทยา 13 พ.ย. 2569
- Dashboard ยอดนัดหมายยังแสดง 3 และเก็บยอดแนะแนวสะสม 48

แก้การแสดงผล:

1. หนังสือที่มีผลแนะแนวเชื่อมแล้วแสดงหมายเหตุสรุป “แนะแนวเรียบร้อยแล้ว” ไม่แสดงข้อความรอติดต่อกลับเป็นงานค้าง ข้อความต้นฉบับยังอยู่ในฐานข้อมูล
2. โรงเรียนที่จบรอบงานแล้วพับหมายเหตุเดิมไว้ในส่วนประวัติ วันนัดเดิมและผลแนะแนวยังเปิดดูได้
3. นัดหมายที่จะมาถึงบน Dashboard ตรวจผลแนะแนวด้วย แม้สถานะนัดหมายเดิมยังไม่เปลี่ยน
4. รายละเอียดนัดหมายไม่แสดงหมายเหตุ/การทำงานต่อของนัดที่มีผลแล้ว
5. ปฏิทินส่งผลแนะแนวเข้ารายละเอียดนัดหมาย เพื่อป้องกันแสดงปุ่มบันทึกผลซ้ำ
6. คอมโพเนนต์แจ้งเตือนกรองนัดที่จบแล้ว และอ่านสถานะรอบโรงเรียนจากข้อมูลเชื่อมโยงแทนสถานะเก่าที่เก็บไว้

ตรวจ `npm run lint` ผ่าน และ `npm test` ผ่าน 405 tests + backend 8 tests ตรวจ localhost ตอบ HTTP 200 ไม่มีการ deploy การตรวจครั้งนี้เป็นข้อมูลสด/ตรรกะ/ชุดทดสอบ ไม่ใช่การยืนยันทุกหน้าด้วยเบราว์เซอร์

ยังคงประวัติและไฟล์ภาพ ไม่แก้วันที่งานหรือรวมรายการอื่นในการตรวจครั้งนี้ รอบใหม่ที่มีหนังสือหรือนัดใหม่หลังจบงานยังดำเนินการต่อได้ตามปกติ
