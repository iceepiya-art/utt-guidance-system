# นำเข้าโรงเรียนจาก DMC / Excel

เปิด **ข้อมูลโรงเรียน → นำเข้าจาก Excel** แล้วเลือก DMC691.xlsx จากเครื่อง

1. เลือกไฟล์ Excel หรือ CSV (ไม่เกิน 25 MB / 50,000 แถว) หากมีหลายแผ่นงานสามารถเปลี่ยนได้
2. เลือกภาค จังหวัด อำเภอ ตำบล และกลุ่มนักเรียน ม.3 / ม.6 เพิ่มเติมได้ด้วยสังกัด ขนาด ขยายโอกาส หรือค้นหาชื่อ/รหัส/เขตพื้นที่
3. เลือกโรงเรียนทีละแห่งหรือทั้งหมดตามตัวกรอง (ครั้งละไม่เกิน 500 แห่ง) เปลี่ยนตัวกรองจะล้างการเลือกเดิมเพื่อไม่ให้มีรายการซ่อนติดไป
4. ตรวจรายชื่อ เลือกสายงานและปีการศึกษา แล้วกดยืนยันนำเข้า
5. ตรวจผล เพิ่มสำเร็จ / ข้ามซ้ำ / ไม่สำเร็จ กรณีผิดพลาดลองเฉพาะรายการที่ไม่สำเร็จได้

ข้อมูลซ้ำตรวจด้วยรหัสโรงเรียน หรือชื่อที่ตัดคำว่าโรงเรียน + จังหวัด + อำเภอ ไม่ทับประวัติและสถานะเดิม
นำเข้าใช้ document ID คงที่และ transaction เพื่อป้องกันสร้างซ้ำเมื่อกดลองอีกครั้ง
สิทธิ์: ADMIN และ STAFF; ฐานข้อมูลตรวจสิทธิ์ด้วย Firestore rules เดิม
ไฟล์อ่านใน Web Worker บนเครื่อง ไม่อัปโหลดไฟล์ต้นฉบับหรือรายชื่อทั้งประเทศไปยังเว็บ
ข้อมูลจะถูกบันทึกเฉพาะหลังผู้ใช้ยืนยันรายการ

## ผลตรวจ DMC691.xlsx

- Sheet1: 28,840 โรงเรียน, 77 จังหวัด, 4 ภาคตามการจัดกลุ่มในไฟล์
- อุตรดิตถ์: 227 โรงเรียน; มีนักเรียน ม.3: 76 โรงเรียน
- พิชัย + มี ม.3: 10 โรงเรียน; ฐานเดิมข้ามซ้ำ 1 แห่ง
- จำนวน ม.3/ม.6 ใช้ยอดรวมในไฟล์; หากไม่มีจึงรวมชายและหญิง ไม่บวกซ้ำ
- ข้อมูลตำบล สังกัด ขนาด เขตพื้นที่ จำนวนผู้เรียนทั้งหมด และชื่อไฟล์ต้นทางเก็บไว้กับโรงเรียนที่นำเข้า
- ข้อมูลผู้ประสานงานที่ไม่มีในไฟล์เก็บเป็นค่าว่าง ไม่ตั้งข้อมูลสมมติ

ทดสอบ parser/filters/duplicates 9 กรณี และ persistence/retry/permission 3 กรณี
ทดสอบ browser ด้วยไฟล์จริงตั้งแต่ upload → กรอง → เลือก → ตรวจสอบ → ยกเลิกและเปิดใหม่ โดยไม่เขียนข้อมูลจริงระหว่างทดสอบ
อัปเดต SheetJS เป็น 0.20.3 จากแหล่งจำหน่ายทางการ: https://docs.sheetjs.com/docs/getting-started/installation/nodejs/
