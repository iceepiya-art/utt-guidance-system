# ผลตรวจและนำเข้าต้นฉบับ UTT — 24 กันยายน 2569

บันทึกเข้า Firestore จริงแล้ว โดยอ่านข้อมูลสดก่อนเขียน สำรองก่อน/หลัง และอ่านกลับตรวจทุกฟิลด์ที่เปลี่ยน ไม่มีการ deploy โค้ด

## ผลดำเนินการ

- อ่านต้นฉบับล่าสุด: หนังสือ 143 รายการ และหน้าข้อมูลแนะแนว 143 รายการ ไม่มีข้อผิดพลาดขณะดึงข้อมูล
- เพิ่มโรงเรียน/หน่วยงานที่ขาด 11 แห่ง ข้อมูลติดต่อและจำนวนนักเรียนที่ต้นฉบับไม่ระบุยังเว้นว่าง
- เพิ่มหนังสือ 14 รายการ และปรับข้อมูล/การเชื่อมโยงหนังสือเดิม 125 รายการ
- เพิ่มนัดหมาย 2 รายการ และปรับการเชื่อมโยงนัดหมายเดิม 46 รายการ
- เพิ่มผลแนะแนวจริง 47 รายการ และเชื่อมผลเดิม 1 รายการ อ้างอิงข้อความผลดำเนินงานในหน้าต้นฉบับ ไม่สร้างจากสถานะนัดหมายเพียงอย่างเดียว
- ใช้รถและผู้ร่วมงานจากตารางที่ผู้ใช้ยืนยันเมื่อจับคู่วัน สาย โรงเรียน และประเภทงานได้แน่นอน ไม่เดาข้อมูลที่ไม่มีหลักฐาน
- คงรูปเดิมและเติมรูปจากต้นฉบับ พร้อมโรงเรียนและรายการผลแนะแนวที่อ้างอิง

จำนวนรวมหลังบันทึก: โรงเรียน 157, หนังสือ 154, นัดหมาย 51, บันทึกออกปฏิบัติงาน 51 รายการ (รวมรายการเดิม)

## การตรวจสอบ

- อ่านกลับจาก Firestore ตรวจค่าทุกฟิลด์ที่บันทึกแล้วผ่าน
- รันแผนนำเข้าซ้ำ: 0 รายการเปลี่ยนแปลง ไม่สร้างข้อมูลซ้ำ
- ผลแนะแนวที่นำเข้าทุกชุดเชื่อมถึงนัดหมายและโรงเรียนที่มีอยู่จริง
- ไชยะวิทยา: ใช้ฟังก์ชันสถานะเดียวกับระบบแล้วได้ `GUIDANCE_COMPLETED`; รอบงานมีหนังสือ 1, นัดหมาย 1, ผลแนะแนว 1, รูป 1
- `npm run lint` ผ่าน
- ตรวจลิงก์รูปต้นฉบับล่าสุด 312 รูป: เข้าถึงได้และเป็นไฟล์ภาพครบ 312 รูป (`backup/utt-evidence-check-2026-09-24.json`)
- `http://localhost:3000/` ตอบ HTTP 200; เปิด Vite เบื้องหลังแล้ว
- ยังตรวจภาพ UI ไม่ได้ เพราะ Browser runtime ไม่มีเบราว์เซอร์ที่เชื่อมต่อ
